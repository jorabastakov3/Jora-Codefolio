
🌐 Jora-Codefolio — Сайт-визитка / Портфолио

Адаптивная одностраничная сайт-визитка и портфолио, написанные на чистом HTML5 и CSS3. Проект предназначен для демонстрации навыков веб-верстки, проектов и контактных данных.

🚀 Живая демо-версия: https://jorabastakov3.github.io/Jora-Codefolio/

🛠 Технологии

HTML5 — семантическая структура страницы.
CSS3 — стилизация, градиенты, адаптивные карточки и плавные анимации (transitions).
GitHub Pages — хостинг и публикация сайта.


📌 Секции сайта

Home (Главная) — приветствие и краткая презентация.
About (Обо мне) — описание пути в IT и текущего стека (HTML, CSS, Python, JS).
Projects (Проекты) — карточки с примерами работ (Лендинг, Python-парсер, Сайт-визитка).
Blog (Блог) — заметки и статьи о программировании.
Contact (Контакты) — ссылки на соцсети (Telegram, GitHub, Email) и форма обратной связи.


📂 Структура проекта

Jora-Codefolio/

    ├── style.css         # Основные стили проекта

    └── images/           # Изображения проектов и иконки
