# 🌐 Jora-Codefolio — Сайт-визитка / Портфолио

Адаптивная одностраничная сайт-визитка и портфолио, написанные на чистом HTML5 и CSS3. Проект предназначен для демонстрации навыков веб-верстки, проектов и контактных данных.

🚀 **Живая демо-версия:** [https://jorabastakov3.github.io/Jora-Codefolio/](https://jorabastakov3.github.io/Jora-Codefolio/)

---

## 🛠 Технологии

* **HTML5** — семантическая структура страницы.
* **CSS3** — стилизация, градиенты, адаптивные карточки и плавные анимации (`transitions`).
* **GitHub Pages** — хостинг и публикация сайта.

---

## 📌 Секции сайта

1. **Home (Главная)** — приветствие и краткая презентация.
2. **About (Обо мне)** — описание пути в IT и текущего стека (HTML, CSS, Python, JS).
3. **Projects (Проекты)** — карточки с примерами работ (Лендинг, Python-парсер, Сайт-визитка).
4. **Blog (Блог)** — заметки и статьи о программировании.
5. **Contact (Контакты)** — ссылки на соцсети (Telegram, GitHub, Email) и форма обратной связи.
